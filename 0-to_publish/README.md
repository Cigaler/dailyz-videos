# 0-to_publish — Rolling 7-Day Publish Queue
This folder always contains 7 days of upcoming content.
Each subfolder is named mm_dd and contains the actual .mp4 file to post that day on @cigaler (TikTok) and @Cigalerr (YouTube Shorts).
After each video is published, the agent removes that day's folder and adds a new one 7 days ahead — the window always rolls forward.
If a video is not ready yet, that dated folder contains a README placeholder instead.
