# DailyZ Channel Setup Guide

This guide is the fastest setup path for DailyZ's first YouTube Shorts channel and TikTok account.

- Brand to use everywhere: `DailyZ Trends`
- Primary handle / username to claim: `@dailyztrends`
- Backup handle order if unavailable: `@dailyztrend`, `@dailyzshorts`, `@dailyz.tv`
- Brand colors:
  - electric lime: `#D8FF3E`
  - near-black: `#101010`
  - warm white: `#F6F6F2`
  - accent orange: `#FF5A36`
- Brand promise: `Daily internet trends, decoded fast.`
- All posting times below are in `US Eastern Time`

## 1. Make The Brand Assets First

Create these `2` files in Canva before opening YouTube or TikTok.

### Profile picture file

- Canva size: `800 x 800 px`
- Export: `PNG`
- Background: solid `#101010`
- Main mark: big `DZ` monogram in `#D8FF3E`
- Accent: make the `Z` a lightning-style slash in `#FF5A36`
- Font direction: condensed bold sans
- Keep the letters centered and thick enough to still read in a tiny circle
- Do not add any small text

Use this same file for both YouTube and TikTok.

### YouTube banner file

- Canva size: `2560 x 1440 px`
- Keep all text inside the centered safe area: `1546 x 423 px`
- Background: `#101010`
- Headline text: `Daily internet trends, decoded fast.`
- Secondary line: `Shorts + TikToks every day`
- Add one lime horizontal bar or accent block in `#D8FF3E`
- Optional small accent shape in `#FF5A36`
- Keep the design clean and bold with no tiny icons
- Export: `PNG`

## 2. YouTube Shorts Channel Setup

### Account details to use

- Channel name: `DailyZ Trends`
- Handle: `@dailyztrends`

### Step-by-step setup

1. Create the YouTube channel under the owner's Google account.
2. Set the channel name to `DailyZ Trends`.
3. Claim the handle `@dailyztrends`.
4. Upload the `800 x 800` profile picture.
5. Upload the `2560 x 1440` banner.
6. Paste the channel description below into the About section.
7. Add the website link `https://dailyz.nanocorp.app`.
8. Add the first `3` channel keywords listed below.
9. Set upload defaults:
   - Visibility: `Private`
   - Audience: `No, it's not made for kids`
   - Language: `English`
   - Category: `Entertainment`
10. Turn on `2-Step Verification` and complete YouTube phone verification.

### Channel description

Paste this exactly:

```text
DailyZ Trends breaks down the internet's biggest trends, memes, apps, creators, and viral moments in fast, faceless Shorts. If your feed is suddenly full of something and you want the context fast, start here. New Shorts every day.
```

### First 3 tags / keywords

Add these `3` first:

- `daily internet trends`
- `internet culture`
- `viral apps`

### First pinned comment template

Paste this under the first Short and pin it:

```text
What trend should DailyZ decode next? Drop it below and subscribe for daily breakdowns.
```

### Shorts upload checklist

Use this every time:

1. Upload the YouTube-specific export only. No TikTok watermark.
2. Keep the Short vertical at `1080 x 1920`.
3. Keep runtime between `30` and `45` seconds when possible.
4. Use a searchable title. Model the title after these exact formats:
   - `Why Everyone Is Talking About This Today`
   - `What Actually Started This Viral Trend`
   - `The 30-Second Breakdown of This Internet Obsession`
5. Paste this description:

```text
DailyZ breaks down internet trends, viral apps, creators, and online chaos fast.
Subscribe for daily trend breakdowns.
#shorts #dailyz #internettrends
```

6. Always use these hashtags:
   - `#shorts`
   - `#dailyz`
   - `#internettrends`
7. Use `2` to `3` hashtags total only.
8. Turn comments on.
9. If the video uses realistic synthetic media, complete YouTube's altered or synthetic content disclosure.
10. Publish at one of the YouTube times listed in the schedule section below.

## 3. TikTok Account Setup

### Account details to use

- Nickname: `DailyZ Trends`
- Username: `@dailyztrends`

### Step-by-step setup

1. Create the account as a `Personal Account`, not a Business Account.
2. Set the nickname to `DailyZ Trends`.
3. Claim the username `@dailyztrends`.
4. Upload the same `800 x 800` profile picture used on YouTube.
5. Paste the bio below.
6. Connect the YouTube account under profile links.
7. If the website field is available, add `https://dailyz.nanocorp.app`.
8. Set the account to `Public`.
9. Turn on `2-step verification`.
10. Turn on comments, downloads, Duet, Stitch, and suggested-account discoverability.

### Bio text

Paste this exactly:

```text
What the internet is obsessed with today, explained in under 60 seconds.
```

### Profile picture spec

Use the same avatar created for YouTube:

- `800 x 800 px`
- `PNG`
- `#101010` background
- `DZ` monogram in `#D8FF3E`
- lightning-style `Z` accent in `#FF5A36`

### Link in bio

Use this website link:

```text
https://dailyz.nanocorp.app
```

If TikTok does not offer the website field yet, leave the bio as-is and connect the YouTube account first.

### First video posting checklist

Use this every time:

1. Upload the TikTok-specific export only. No other platform watermark.
2. Keep the video vertical at `1080 x 1920`.
3. Keep at least one original TikTok per day in the `60` to `90` second range.
4. Turn on auto captions.
5. Use keyword-rich spoken audio and on-screen text in the first `2` seconds.
6. Paste this caption:

```text
If your feed is suddenly full of this, here's the fast explanation. Follow @dailyztrends for daily trend breakdowns. #dailyz #internettrends #explained #genz #trendalert
```

7. Keep the sound strategy simple:
   - Use the original DailyZ voiceover as the main audio.
   - Add one in-app trending sound only when it matches the topic.
   - Keep the added sound low at roughly `8%` to `12%` volume so the narration stays clear.
   - Skip the trending sound entirely if it makes the explanation harder to follow.
8. Post with comments on and visibility set to `Everyone`.
9. Publish at one of the TikTok times listed in the schedule section below.

## 4. Posting Schedule

### Exact daily times

Use this default weekly schedule for the first `30` days:

| Platform | Time 1 | Time 2 | Time 3 |
| --- | --- | --- | --- |
| YouTube Shorts | `12:30 PM` | `6:30 PM` | — |
| TikTok | `11:00 AM` | `3:00 PM` | `8:30 PM` |

### Strongest priority windows

- YouTube Shorts strongest window: `Thursday to Sunday, 6:00 PM to 8:00 PM`
- YouTube Shorts strongest single-day burst: `Friday, 4:00 PM to 7:00 PM`
- TikTok strongest window: `Tuesday to Thursday, 2:00 PM to 6:00 PM`
- TikTok secondary evening test window: `8:00 PM to 10:00 PM`

### Platform-first rule

Use this order when the same concept goes to both platforms:

1. Post the longer, original cut on TikTok first.
2. Post the tighter recut on YouTube Shorts after that.
3. Never cross-post a watermarked file.

### What goes where first

- TikTok first:
  - trend reactions
  - meme and creator-news breakdowns
  - anything that benefits from trending sound and same-day speed
- YouTube Shorts second:
  - the tighter `30` to `45` second recut of the same topic
  - cleaner, more searchable versions of the explanation
