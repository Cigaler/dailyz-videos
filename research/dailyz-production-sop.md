# DailyZ Production SOP: 1 AI Short Video Per Day

This SOP is the daily operating procedure for publishing `1` DailyZ short video per day with:

- no camera
- no studio
- AI tools only
- one non-technical operator
- total production time under `60 minutes`

## Fixed Daily Rules

- DailyZ topic focus: `AI tools / SaaS / workflow automation`
- DailyZ video promise: `one useful AI workflow or tool explained fast`
- Target runtime: `35 to 45 seconds`
- Target format: vertical `9:16`
- Export size: `1080x1920`
- Make separate exports for YouTube Shorts and TikTok so nothing carries another platform's watermark

## Daily Tool Stack

- Trend research:
  - TikTok Creative Center: `https://ads.tiktok.com/business/creativecenter/trends/hub/pc/en`
  - YouTube Studio: `https://studio.youtube.com/`
  - Google Trends: `https://trends.google.com/trends/explore?geo=US&hl=en`
- Script and voice:
  - ElevenLabs Text to Speech: `https://elevenlabs.io/app/speech-synthesis/text-to-speech`
- Editing:
  - CapCut desktop or web
- Cover art:
  - Canva YouTube thumbnail maker: `https://www.canva.com/create/youtube-thumbnails/`

## 1. Trend Check (`5 min`)

Goal: pick `1` topic that is timely, easy to explain, and easy to visualize.

### Open these exact URLs

1. TikTok Creative Center:
   `https://ads.tiktok.com/business/creativecenter/trends/hub/pc/en`
2. YouTube Studio:
   `https://studio.youtube.com/`
3. Google Trends:
   `https://trends.google.com/trends/explore?geo=US&hl=en`

### What to look for

Pick topics that match all `3` rules:

1. It is about an `AI tool`, `AI workflow`, or `AI vs AI` comparison.
2. It solves one real task fast, such as:
   - budgeting
   - email cleanup
   - spreadsheet cleanup
   - search
   - note-taking
   - coding
   - resume writing
3. You can explain the value in one sentence:
   - `This tool saves time on [task].`
   - `This workflow replaces [old process].`
   - `This update matters because [clear benefit].`

### 5-minute trend routine

#### Minute 1 to 2: TikTok Creative Center

- Check the current trending topics, hashtags, and creative patterns.
- Look for repeated words connected to:
  - AI
  - apps
  - productivity
  - work
  - money
  - creators
- Write down `3` possible topics.

#### Minute 3 to 4: YouTube Studio Trends

- In YouTube Studio go to `Analytics` -> `Trends`.
- If your account shows `Inspiration` or `Research` instead of `Trends`, use that area.
- Search your `3` topic ideas one by one.
- Keep the topic if people are actively searching for it and the idea sounds useful as a short explainer.

#### Minute 5: Google Trends

- Compare your best `2` ideas in the US.
- Choose the one with the cleaner upward line or clearer recent spike.

### Topic selection rule

Choose today's topic only if it passes this filter:

- `Trend`: it is moving on TikTok, YouTube, or Google right now
- `Utility`: it helps with one real task
- `Visuals`: you can show screen grabs, stock footage, or simple text slides

If a topic fails even one of those, skip it.

### Best Daily Topic Formula

Use this format:

`[Tool or update] + [specific task] + [why it matters now]`

Examples:

- `ChatGPT budget workflow for weekly money check-ins`
- `Google AI Mode for research faster than regular search`
- `Claude vs ChatGPT for spreadsheet cleanup`

## 2. Script Writing (`10 min`)

Goal: write one short script that sounds fast, clear, and useful.

### Word count targets

- Hook: `8 to 12` words
- Body: `45 to 75` words
- CTA: `10 to 16` words
- Total: `65 to 100` words

That should land around `35 to 45 seconds` in a normal AI voice.

### Script structure

- First `3 seconds`: hook
- Next `15 to 30 seconds`: body
- Last `5 seconds`: CTA

### DailyZ script template

Copy this and fill in the blanks:

```text
HOOK
If you still use [old way], this [tool/workflow] is faster.

BODY
Here is the shortcut. Use [tool] to [task].
The win is [specific result].
What makes this matter today is [trend peg or update].
If you want the fastest version, do these 3 steps:
1. [step one]
2. [step two]
3. [step three]

CTA
Follow DailyZ for one AI workflow you can steal tomorrow.
```

### Fast writing rules

- Use short sentences.
- Say the tool name in the first line.
- Mention one concrete outcome:
  - `save 20 minutes`
  - `replace 3 apps`
  - `clean a messy CSV`
  - `write a tailored resume`
- Do not use more than `3` main points.
- Do not add background history unless it helps the payoff.

### Hook formulas

Use one of these:

- `This AI workflow replaces [old task] in minutes`
- `Everyone is testing [tool], but this is the useful part`
- `This [tool] just made [annoying task] feel outdated`
- `Before you pay for another app, try this first`

### CTA formulas

Use one of these:

- `Follow DailyZ for one useful AI workflow every day`
- `Save this, then try it before work tomorrow`
- `Follow for the next AI tool worth stealing`

## 3. Voiceover in ElevenLabs (`10 min`)

Goal: turn the script into one clean narration file.

### DailyZ house voice

Use:

- Voice: `Janet`

Why this voice:

- clear
- neutral
- fast enough for explainers
- fits DailyZ's sharp, faceless news/explainer style

If `Janet` is not visible in your account, use the closest neutral US-English narrator voice and save it as your fixed DailyZ default.

### Exact workflow

1. Open:
   `https://elevenlabs.io/app/speech-synthesis/text-to-speech`
2. Paste the final script.
3. Select voice: `Janet`
4. Keep advanced settings at default on the first pass.
5. If the read feels too fast, slightly reduce speed.
6. Click `Generate speech`.
7. Listen once from start to finish.
8. If one word sounds wrong, edit the script text and regenerate.
9. Download the final file.

### Export settings

- First choice: `WAV`
- Backup choice: `MP3 (128 kbps)`
- File name: `voice.wav` or `voice.mp3`

### ElevenLabs quality rules

- Put each sentence on its own line if the pacing sounds rushed.
- Write numbers the way you want them spoken.
  - Example: write `three apps` instead of `3 apps` if pronunciation sounds awkward.
- Spell hard product names clearly.
- Do not spend more than `2` regeneration attempts on one script.
  If it still sounds wrong, simplify the script and move on.

## 4. Video Assembly in CapCut (`20 min`)

Goal: build one polished vertical short with captions, supporting visuals, and light music.

### Create the project

1. Open CapCut.
2. Create `New project`.
3. Set the canvas to vertical `9:16`.
4. Import the voiceover file first.

### Build in this order

1. Put the voiceover on the timeline.
2. Break the script into `5 to 8` visual beats.
3. Add visuals above the voice track.
4. Add captions.
5. Add background music last.

### What visuals to use

Use a mix of:

- CapCut stock footage
- CapCut stock images
- screenshots of the tool or workflow
- simple text slides
- Canva cover art as the first frame if needed

### Visual pacing rules

- Change visuals every `1 to 3 seconds`
- Put the strongest text on screen in the first second
- Use zoom, crop, or position changes so static screenshots feel alive
- Keep only one main idea on screen at a time

### Recommended timeline structure

- `0:00 to 0:03`
  - biggest hook text on screen
  - strongest visual first
- `0:03 to 0:25`
  - show the `2 to 3` key steps or examples
- `0:25 to 0:40`
  - show payoff, result, or comparison
- `last 5 seconds`
  - CTA text
  - DailyZ handle or brand tag

### Add captions

1. Use CapCut `Auto Captions` / `Recognise Subtitles`.
2. Select `English`.
3. Generate captions.
4. Quickly fix product names and obvious mistakes.
5. Apply one consistent style.

### DailyZ caption style

- font: bold sans
- text color: white
- keyword highlight: lime green
- caption box: black or very dark charcoal
- max `6` words per line
- keep captions in the center-safe area so TikTok and YouTube UI do not cover them

### Add music

1. Pick light instrumental background music from CapCut's library.
2. Keep it low.
3. The voice must always be easy to hear.

Rule:

- If the music competes with the voice, lower it again.

### Export settings

Use:

- aspect ratio: `9:16`
- resolution: `1080x1920`
- frame rate: `30 fps`
- format: `MP4`

### Final CapCut checklist

Before export, confirm:

- no watermark
- no empty pause at the start
- captions are readable on a phone
- first frame is strong enough to use as a cover
- audio is clear
- total runtime is under `60 seconds`

## 5. Thumbnail / Cover in Canva (`5 min`)

Goal: make one reusable cover style that matches DailyZ branding.

### Canva template spec

Create one design in Canva with these settings:

- canvas size: `1080x1920`
- use it as a cover card and as a frame reference for both platforms

### Design rules

- headline: `3 to 5` words only
- large main text at the top or center
- one supporting image only:
  - app screenshot
  - product logo
  - simple stock background
- dark overlay behind text for readability

### DailyZ visual style

- primary color: `#D8FF3E`
- secondary color: `#101010`
- background neutral: `#F6F6F2`
- accent color: `#FF5A36`

### Cover text formulas

- `FREE AI RESEARCH`
- `BETTER THAN GOOGLE?`
- `THIS REPLACES 3 APPS`
- `FASTEST CSV FIX`
- `THE ONLY AI TOOL?`

### Export

- export as `PNG`
- file name: `cover.png`

### How to use it

- Either add the cover as the first `0.5 to 1 second` frame in CapCut
- Or use it as the visual guide for the frame you pick inside YouTube Shorts and TikTok

## 6. Posting (`5 min`)

Goal: upload cleanly, fill the same fields every time, and avoid overthinking metadata.

## YouTube Shorts posting checklist

### Where to post

- Open: `https://studio.youtube.com/`
- Click `Create` -> `Upload videos`

### Fill these fields

- Title
- Description
- Audience
- Category
- Language
- Visibility

### Exact field rules

- Title:
  - `45 to 60` characters
  - keyword first
  - clear result second
  - example:
    - `ChatGPT Budget Workflow That Replaces 3 Apps`
- Description:
  - `1 to 2` short lines
  - line 1 = what the video explains
  - line 2 = CTA
  - example:
    - `A fast ChatGPT workflow for weekly budget reviews.`
    - `Follow DailyZ for one useful AI workflow every day.`
- Hashtags:
  - put at the end of the description
  - use exactly `2 to 3`
  - default set:
    - `#shorts`
    - one topic tag
    - `#dailyz`
- Audience:
  - `No, it's not made for kids`
- Category:
  - `Science & Technology`
- Language:
  - `English`
- Visibility:
  - `Public`
  - or schedule it for the planned slot

### Cover frame rule

- Choose a frame from `0:01 to 0:03`
- The text must be readable with no platform UI covering it
- If needed, use the YouTube app after upload to set the Short's frame more precisely

### YouTube posting rule

- Do not stuff tags.
- The title and first line of the description matter more.

## TikTok posting checklist

### Where to post

- Open the TikTok app
- Tap `+`
- Upload the finished TikTok export

### Fill these fields

- Description
- Hashtags
- Cover
- Privacy
- Comments
- Duet
- Stitch

### Exact field rules

- Description:
  - `80 to 120` characters before hashtags if possible
  - start with the key topic
  - example:
    - `ChatGPT can handle your weekly budget review faster than 3 finance apps.`
- Hashtags:
  - use `4 to 6`
  - default set:
    - `#dailyz`
    - `#aitools`
    - `#explained`
    - one or two topic-specific tags
    - one discovery tag like `#productivity` or `#workflow`
- Cover:
  - pick the clearest frame from `0:01 to 0:03`
  - if TikTok lets you add cover text, repeat the same `3 to 5` word Canva headline
- Privacy:
  - `Everyone`
- Comments:
  - `On`
- Duet:
  - `On`
- Stitch:
  - `On`

### TikTok AI label rule

- If the post uses realistic AI-generated visuals or AI-generated voice, add clear disclosure in the caption or on-screen text.
- Simple version:
  - add `AI voiceover` in the description
  - or add `#ai`

## Done Definition

The video is done only when all of this is true:

- topic chosen from a real trend check
- script is under `100` words
- voiceover exported
- video exported at `1080x1920`
- captions checked
- cover frame chosen
- YouTube Shorts posted
- TikTok posted

If one of those is missing, the video is not done.
