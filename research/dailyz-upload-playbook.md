## 3. YouTube Shorts Upload Steps

Use desktop `YouTube Studio` for the upload itself, then use the YouTube mobile app only if you want to fine-tune the Shorts cover frame.

### Exact UI flow

1. Sign in to the DailyZ Google account and open `YouTube Studio`.
2. Click `Create` in the top-right corner.
3. Click `Upload videos`.
4. Drag in the target file from `output/videos/` or click `SELECT FILES`.
5. On the `Details` screen:
   - paste the exact `Title` from the metadata section below
   - paste the `Description`
   - paste the YouTube hashtag set at the end of the description on a new line
6. Leave playlists empty unless you create a Shorts playlist later.
7. Set `Audience` to `No, it's not made for kids`.
8. Open `Show more` and set:
   - `Language`: `English`
   - `Category`: `Science & Technology`
   - `Comments`: `Allow all comments`
9. If YouTube asks about altered or synthetic content, answer honestly. These videos use AI-generated narration and should be disclosed if prompted.
10. Click `Next` through `Video elements`.
11. Let `Checks` finish.
12. On `Visibility`, choose `Schedule`.
13. Set the exact date and time from the posting schedule table above.
14. Click `Schedule`.

### How to make sure it publishes as a Short

There is no separate Shorts toggle to switch on in the desktop uploader. For DailyZ, the rule is simple:

- keep the file vertical `9:16`
- keep it under `60` seconds
- upload the `.mp4` as-is

All four DailyZ files already meet that requirement.

### Where to paste title, description, and hashtags

- `Title` box: paste the exact YouTube title
- `Description` box: paste the description first
- same `Description` box, last line: paste the YouTube hashtag line

### Thumbnail / cover-frame rule

For Shorts, pick a frame from the video instead of trying to design a separate thumbnail.

- best frame window: `0:01` to `0:03`
- choose a frame where the hook text is readable and not blocked by UI
- if you want to adjust it after upload, open the YouTube app on your phone, open the Short, tap `Edit`, then `Edit thumbnail`, scrub to the best frame, and save

### Best posting time for YouTube Shorts

For this starter batch, use `6:30 PM ET`. That matches the DailyZ calendar for dual-platform posts and sits inside the stronger evening Shorts window.

## 4. TikTok Upload Steps

Use the TikTok mobile app, not the browser uploader, whenever you want the cleanest control over cover frame and sound.

### Exact UI flow

1. Open the TikTok app while logged in to `@dailyztrends`.
2. Tap the `+` button.
3. Tap `Upload`.
4. Select the target video file.
5. Tap `Next`.
6. On the edit screen:
   - do not trim unless something is obviously broken
   - tap `Sound` only if you want to add one relevant trending sound
   - keep the original DailyZ voiceover as the main audio
7. Tap `Next` again to reach the post screen.
8. In the caption field:
   - paste the exact TikTok caption from the metadata section
   - paste the TikTok hashtag set after the caption
9. Tap `Cover` or `Select cover`.
10. Scrub to the clearest frame between `0:01` and `0:03`.
11. If TikTok offers cover text, repeat the short hook from the first frame.
12. Set:
   - `Who can view this video`: `Everyone`
   - `Allow comments`: `On`
   - `Allow Duet`: `On`
   - `Allow Stitch`: `On`
13. Post it at the scheduled time.

### Sound settings

Keep this simple:

- default: original DailyZ narration only
- optional: add one relevant trending sound if it fits the topic
- if you add sound, keep it low so the narration is still clearly dominant
- skip background sound entirely if it makes the explanation harder to follow

### Cover-frame rule

- choose the cleanest frame from `0:01` to `0:03`
- make sure the big hook text is readable on a phone
- avoid frames where TikTok UI blocks the headline

### Best posting time for TikTok

For this starter batch, use `3:00 PM ET`. That matches the content calendar and sits inside TikTok's stronger weekday afternoon window.
