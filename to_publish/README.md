# 📅 to_publish — Rolling 7-Day Publish Queue
This folder always contains 7 days of upcoming content.
Each subfolder is named mm_dd and contains the video(s) to post that day on @cigaler (TikTok) and @Cigalerr (YouTube Shorts).
After each video is published, the agent removes that day's folder and adds a new one 7 days ahead — the window always rolls forward.
Videos are stored at videos/v3/ in this repo.
